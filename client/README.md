# Portfolio Website

Personal portfolio website built with React 19 and Vite.

## Highlights

- Animated galaxy background and smooth section transitions
- Work Experience timeline with scroll-linked visual effects
- Projects showcase with detailed stack and live/demo links
- Responsive design for desktop and mobile

## Tech Stack

- React 19
- Vite
- Tailwind CSS 4
- JavaScript (ES Modules)
- ESLint

## Getting Started

### Prerequisites

- Node.js 18+
- npm

### Install

```bash
npm install
```

### Run Development Server

```bash
npm run dev
```

### Build for Production

```bash
npm run build
```

### Preview Production Build

```bash
npm run preview
```

### Lint

```bash
npm run lint
```
